# Розсилач листів (Apps Script)

Надсилає HTML-листи власнику акаунта Google і читає його відповіді на чернетки. У репозиторії немає ні адреси, ні секрету.

## Розгортання (один раз, ~5 хв)
1. script.google.com → **Новий проєкт** → назва `krzhv-mailer` (окремий проєкт, не змішувати з ботами).
2. Замінити вміст `Code.gs` на файл `scripts/mailer/Code.gs` з репозиторію.
3. **Налаштування проєкту** (шестерня) → **Властивості скрипту** → додати `TOKEN` = довгий випадковий рядок (30+ символів). Збережіть його в менеджері паролів.
4. **Розгорнути** → **Нове розгортання** → тип **Веб-застосунок** → «Виконувати від імені»: **Я**; «Хто має доступ»: **Усі**. Підтвердити дозволи Gmail (одноразово).
5. Скопіювати адресу `.../exec`.
6. У налаштуваннях середовища, де працює агент, додати змінні `KRZHV_MAIL_URL` (адреса з кроку 5) і `KRZHV_MAIL_TOKEN` (токен з кроку 3). Не надсилайте їх у чат і не додавайте в репозиторій.

Захист: без токена скрипт відхиляє запит; адресат листа завжди власник акаунта (інший адрес вказати неможливо).
