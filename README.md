# Сайт krzhv.pp.ua

Сайт побудований на Eleventy (11ty). При кожному push у гілку `main` GitHub Actions автоматично збирає сайт і публікує на GitHub Pages.

## Як додати нову статтю для клієнтів

1. На GitHub відкрий папку `src/statti/`
2. Натисни **Add file → Create new file**
3. Назви файл латиницею, напр. `depresiya.md`
4. Встав такий текст на початку файлу (це метадані — заповни своїми значеннями):

```
---
layout: article.njk
title: "Заголовок статті"
description: "Короткий опис для пошукових систем (1-2 речення)"
category: "Категорія (напр. Настрій)"
date: 2026-08-20
section: statti
sectionLabel: "Матеріали"
sources:
  - "Джерело 1"
  - "Джерело 2"
---
```

5. Далі пиши текст статті звичайним Markdown:
   - `## Заголовок` — підзаголовок розділу
   - `**текст**` — жирний текст
   - `- пункт` — маркований список
   - `![Опис](../images/statti/slug-статті/файл.jpg)` — вставка зображення (спочатку завантаж зображення в папку `src/assets/images/statti/<slug статті>/` через "Add file → Upload files")

6. Внизу сторінки натисни **Commit changes** — за 1-2 хвилини стаття з'явиться на сайті, а sitemap.xml/robots.txt/llms.txt оновляться автоматично.

## Як додати новий запис у блог

Те саме, але в папці `src/blog/`, і замість `category` вказуєш:

```
audience: colleagues
```
або
```
audience: journal
```

## Як додати новий відгук

Відкрий файл `src/_data/testimonials.json`, додай новий об'єкт у масив за зразком тих, що вже є:

```json
{
  "text": "Текст відгуку",
  "who": "Клієнтка, 30 років",
  "topic": "Тривога"
}
```

## Локальна перевірка (опційно, для розробника)

```
npm install
npm run serve   — запускає локальний перегляд на http://localhost:8080
npm run build   — збирає готовий сайт у папку _site/
```
